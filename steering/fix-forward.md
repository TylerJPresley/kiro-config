# Fix forward

Intent: existing work and shared systems are preserved by correcting forward, so progress and context are kept.
Applies: when something is wrong, and before any action that is hard to undo or reaches outside the project.

- Fix forward. When something is wrong, find the cause and make the next change that moves the work toward the blueprint. A correction is a new change on top of the history, and the mistake becomes a lesson.
- For anything hard to undo, say what it does and wait for a yes.
- Back up a file before editing it outside the project, in `_internal/backups/`.
- Publish and deploy only when the owner asks.
