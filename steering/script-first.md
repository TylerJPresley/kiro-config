# Script first

Intent: mechanical work goes to deterministic scripts; models decide and design.
Applies: when a task is work a program can decide.

- Mechanical work goes to scripts: anything a program can decide, such as counting, listing, searching, comparing, validating, converting, running tests and summarising logs. Models decide and design.
- Look for an existing script first. When a new one will be needed again, save it where the next session finds it.
- A rule a program can check becomes a check: a lint rule, a test or a gate.
- Report what the script printed, short, with a pointer to the full log.
- Scripts fit work that is repeated, large, or must be provable; a one-off edit is done directly.
