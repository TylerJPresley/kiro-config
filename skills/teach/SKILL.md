# Teach

Intent: durable, long-term retention of a subject, built in a workspace that teaches from primary sources and continues across sessions through its files rather than the conversation.

## When to use
- Learning a subject over time, where the goal is to still know it later.
- Returning to a subject already started, to continue from where the workspace left off.

## How to work
1. Write `MISSION.md` first: what the learner wants to know, their starting point, and how mastery is measured. Teaching begins only once the mission is set.
2. Build `RESOURCES.md` from vetted primary sources, and teach from those sources. Each lesson cites inside itself, and the learner reads at least one primary source per lesson directly.
3. Build for storage strength, not easy recall: use desirable difficulty, retrieval practice, spacing and interleaving so the material is harder now and remembered longer.
4. Keep the workspace files current so a later session resumes from them, not from conversation memory. `references/workspace.md` holds the file layout.
5. Record what the learner has practiced and recalled in the learning records, so spacing and interleaving draw on real history.
