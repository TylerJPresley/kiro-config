# Teaching workspace

The workspace holds the state of learning so a session continues from the files, not from conversation memory. It lives in the learner's working area.

## Files

- `MISSION.md` (required first): the subject, the learner's goal and starting point, and how mastery is measured. No teaching happens until this exists.
- `RESOURCES.md`: the vetted primary sources teaching draws on, each with its origin and why it is trusted.
- `lessons/`: one file per lesson. Each lesson cites its sources inside itself and names the primary source the learner reads directly.
- `reference/`: distilled notes the learner returns to between lessons.
- `learning-records/`: one record per session of what was practiced and recalled, so spacing and interleaving draw on real history.

## How the files drive retention

- A new session reads `MISSION.md` and the latest `learning-records/` entry to decide what to revisit and what to introduce.
- Spacing comes from the dates in the learning records: material due for recall is scheduled before new material.
- Interleaving mixes subjects from earlier lessons into the current one rather than massing one topic.
- Retrieval practice asks the learner to produce an answer before it is shown; the record notes what was recalled and what was missed.
- Desirable difficulty keeps the practice harder than passive review, because effortful recall is what builds storage strength.
