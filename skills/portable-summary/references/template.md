# Portable summary template

Fill each section in plain words. A reader with no access to the original session should be able to continue from this alone.

```
# <title of the work>

## Goal
<the one-sentence outcome this work drives toward>

## State
<where the work stands now: what is done and what is in progress>

## Next step
<the single concrete action to take first>

## Decisions made
- <decision> — <reason>

## Decisions open
- <question still to settle, with a recommended answer if there is one>

## Artifacts
- Files: <paths changed or added>
- Plan: <path>
- Research: <paths or index entries>
- Verify: <the command(s) that check the work>
```
