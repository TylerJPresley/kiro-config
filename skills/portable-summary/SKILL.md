# Portable summary

Intent: capture a piece of work so another session, person or tool can pick it up and continue with no access to the original context.

## When to use
- A session hands off to a fresh one.
- Work passes to another person or another tool.
- A result must be reconstructed later without the conversation that produced it.

## How to work
1. State the goal and where the work stands now, in plain words a reader with no context follows on one read.
2. Name the next step concretely, so the reader knows what to do first.
3. List the decisions already made, each with its reason, and the decisions still open.
4. Point to the artifacts: the files changed, the plan, the research, and the commands that verify the work.
5. Keep it short and current, and follow the template so every handoff carries the same parts.
