# Web engineering

- Performance is a feature: optimize the critical rendering path and Core Web Vitals; compress (gzip/Brotli), lazy-load non-critical routes, use responsive images (srcset) in modern formats (WebP/AVIF) with tiered caching.
- Accessibility: WCAG 2.1 AA, mobile-first responsive layouts, semantic HTML (`<button>`, `<main>`), `aria-label` where semantics are not enough, immediate visual feedback for every user action.
- Technical SEO is foundational: sitemap.xml, robots.txt, JSON-LD structured data. Choose the rendering strategy (SSR, SSG, ISR) by how dynamic the page is and its SEO needs.
- Atomic design: small, reusable, testable components.

Prevents: slow pages, inaccessible UI, invisible content.
