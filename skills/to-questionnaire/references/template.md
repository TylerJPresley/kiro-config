# Questionnaire template

Fill one block per question. Keep each question standing on its own, so the reader can answer without the surrounding context.

```
# Questions on <topic>

## <group name>

1. <question stated plainly>
   - What it decides: <why the answer matters to the work>
   - a. (Recommended) <option, with its reason>
   - b. <alternative>
   - c. <alternative>

2. <next question>
   - What it decides: <...>
   - a. (Recommended) <option>
```

Where a question has no sensible lead, drop the lettered options and leave it open for a free answer. Record each answer beside the question, or in the handoff, so the work finds it.
