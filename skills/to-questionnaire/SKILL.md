# To questionnaire

Intent: convert a blocking unknown into a clear questionnaire the right person answers in one pass, so work resumes without a back-and-forth.

## When to use
- Work is blocked on facts or decisions that only someone else holds.
- Several open questions can be gathered and answered together.
- A back-and-forth would cost more than one well-formed set of questions.

## How to work
1. List every open question the work is blocked on, and drop any the instruction, the code or the research already settles.
2. Group the questions so a reader moves through related ones together.
3. Write each question so it stands on its own: state what it decides and why it matters, in plain words.
4. Offer two or three options with a recommended default wherever a choice has a sensible lead, so the answer can be a single pick.
5. Send the questionnaire to the person who knows, and record each answer where the work will find it; the template holds the layout.
